# Práctica Profesional 


## Introducción y Objetivo


El sector agropecuario es clave en el desarrollo de las sociedades, 
especialmente en las no desarrolladas. Su relevancia varía según el país, 
esto motiva comparar la confianza de los productores entre economías. 
El *Ag Barometer Austral* mide la confianza del productor argentino (Universidad Austral, elaborado desde 2018) 
y el *Ag Economy Barometer* la del productor norteamericano (Universidad *Purdue*, elaborado desde 2015).
Este trabajo tuvo como objetivo comparar, desde una perspectiva exploratoria, 
la evolución temporal de ambos índices y estudiar qué factores están asociados
a la confianza de los productores.



El documento `Informe/Informe.pdf` es un resumen del trabajo realizado en 
el Centro de Agronegocios y Alimentos de la Universidad Austral
entre los meses agosto y octubre de 2026, bajo el concepto del desarrollo de una 
práctica profesional para terminar la carrera de Licenciatura en Estadística 
de la Facultad de Ciencias Económicas y Estadística de la Universidad Nacional 
de Rosario.

### Instrucciones para clonar el repositorio



1. En la terminal de RStudio escribir:

```bash
git clone https://github.com/patricia-nsc/Practica-Profesional-Privado.git
cd Practica-Profesional-Privado
```

2. En la consola de R instalar el siguiente paquete (en caso de no tenerlo):

```r
install.packages("renv")
```

3. Para disponer de todos los paquetes que fueron utilizados para hacer el análisis
correr en la consola de R:


```r
renv::restore()
```
